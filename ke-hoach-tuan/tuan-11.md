# Tuần 11 (04/01 - 10/01): Mini project riêng, câu hỏi tình huống

**Mục tiêu tuần**
- Mini project riêng: dùng lại framework của khóa (POM + Component + TestNG + Allure) cho 1 web demo khác, viết 10-15 test.
- Luyện câu hỏi tình huống Senior/Manager và câu hỏi về automation strategy.
- Đạt 40+ câu trong ngân hàng câu hỏi.
- Học 48 từ (Bài 41-44).

> Nếu đang chậm hơn mốc 1 tuần: bỏ mini project, dùng giờ automation để hoàn thiện project của khóa.

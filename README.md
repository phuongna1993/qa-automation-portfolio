# folder_personal

Personal workspace — home office design (Vietnamese) and misc notes. Not a git repository, just a working folder.

## Contents

- **canvas.json** — layout manifest for the Claude Design canvas: positions/sizes of the three artboards below on one pan/zoom canvas.
- **Main.dc.html** — floor plan artboard: *"Phòng làm việc tối giản — 2 người · 3 trạm"* (minimalist home office, 2 people / 3 stations, 560×430 cm / ~24 m²).
- **Isometric3D.dc.html** — isometric 3D view artboard of the same layout.
- **MoodBoard.dc.html** — mood board artboard (materials, colors, references) for the design.
- **home-office-toi-gian.html** — standalone rendered export of the home office design (large single HTML file, viewable directly in a browser).
- **English/note.md** — currently empty; scratch notes.

## Viewing the design

- Open `home-office-toi-gian.html` directly in a browser for the finished, self-contained view.
- The `.dc.html` files are Claude Design canvas artboards driven by `canvas.json`; open them together through the Claude Design canvas viewer rather than as plain HTML to get the intended pan/zoom layout.
